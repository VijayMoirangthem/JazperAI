## Windows / environment facts to respect

* Node v24.19.0 (type stripping on). Python backend venv at `backend/.venv/Scripts/python.exe`.
* Backend `http://127.0.0.1:8000` (use 127.0.0.1, not `localhost`, which cost ~210 ms/call per the repo history), renderer `http://localhost:5173`.
* Docker holds Postgres, Redis, MinIO. Do not stop or restart them. Do not start new containers in this plan.
* Unpinned `pip install --upgrade` is forbidden (FastAPI 0.111, Starlette 0.37, Pydantic 2.7 are pinned). This plan installs **no** Python or npm packages.
