# Context too large

The conversation plus memory exceeded the model's window.

## Steps
1. Delete chat history for that bot (chat menu) or start a new chat.
2. Switch the bot to a model with a larger window.
3. Lower the memory scopes for the bot in Behaviour.

## Escalate
If this does not fix it, ask Jasper (it can read `alerts`) or Incident Response; record the cause in `docs/ops/` when it was not obvious.
