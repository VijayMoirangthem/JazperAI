# Insufficient funds (402)

The account behind this provider has no credit.

## Steps
1. Top up the account (OpenCode Zen: opencode.ai dashboard).
2. Meanwhile route bots to a free model (Groq) via bot settings > Model, or Automatic.
3. Press Test in the catalogue to confirm.

## Escalate
If this does not fix it, ask Jasper (it can read `alerts`) or Incident Response; record the cause in `docs/ops/` when it was not obvious.
