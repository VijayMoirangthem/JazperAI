# Sir Jazper — Prompt Library

# Resume Optimization Prompt

Analyze the job description.

Extract:
- important keywords
- required skills
- ATS requirements
- experience expectations

Then optimize the resume accordingly.

Rules:
- NEVER fabricate information
- NEVER fake experience
- ONLY optimize existing content
