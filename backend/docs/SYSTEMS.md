# COOS Systems

COOS is organized into eight logical systems, all interconnected through Jazper
and the orchestration layer.

## Personal

Mood, Habits, Focus, Voice Journal, Memory, Mind Simulation (Phases).

## Career

Jobs, Apply, Applications, Radar, Resume, Interview Prep, Salary Coach,
Offer Evaluator, Networking.

## Communications

Gmail, Email Triage, Compose, Analytics, Follow-Ups, Calendar, Contacts,
Templates, Reminders.

## Intelligence

Memory Graph, Knowledge Base, Shared Memory, Search, Sage Memory, History,
Digest.

## Productivity

Tasks, Daily Planner, Sprints, Goals, Daily Standup, Task Priority, Timeline,
Logs.

## Creative

Portfolio, Voice Journal, Reading List.

## Business

Clients, Projects, Finance, Automation, Workflows, Webhooks, Browser.

## Agent OS

Agents, Marketplace, Evolution Log, IT Department, Approvals, Pipeline, IDE,
DB Changes, Model Costs, QA, Observatory, **Command Center** (office floor,
terminals, messages, activity, tasks).

## Cross-cutting

- **Jazper** - global orchestrator / GOD agent; the human's primary interface.
- **Hive** - per-agent workspace, mailboxes, board, task kanban, fleet telemetry.
- **Approvals** - human gate for risky agent actions.
- **Audit** - evolution log, db change log, activity feed.
