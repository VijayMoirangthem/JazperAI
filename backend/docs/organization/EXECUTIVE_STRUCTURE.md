# Executive Structure

## Small business mode

```
Owner (human)
    └── Jazper (orchestrator)
            ├── Marketing
            ├── Finance
            ├── Engineering
            ├── HR
            ├── Operations
            └── Sales
```

One person + Jazper + virtual department agents.

## Growth mode

```
Owner
    └── Jazper
            └── Executive floor(s)
                    ├── C-suite heads (by function)
                    ├── Department heads
                    ├── Managers
                    └── Teams → Agents / Employees
```

## COOS HQ visualization

- **Floor 1** often holds core operations departments.
- Additional **divisions** = additional floors (switch via floor dropdown).
- **Org chart** overlay shows Division → Dept → Team → Agent; click focuses floor.

God agent (Jazper) uses Command Center in desktop mode; Profile tab in COOS HQ mode.
